\## 💛 项目简介



\*\*仁归\*\* 旨在为每一个渴望独处、反思或情绪疏导的灵魂，提供一个 \*\*安全、私密、免费\*\* 的精神家园。



\- 所有数据仅保存在本地服务器，无需上传任何云端。

\- 一键启动后端服务，浏览器访问即可开启属于你的心灵旅程。

\- 永久公益性质，拒绝任何商业化滥用。



\### 核心理念

\- 🌱 \*\*治愈\*\*：用温柔的 AI 回应，化解情绪低谷。

\- 📝 \*\*记录\*\*：心情日记，留存生活的每一丝痕迹。

\- 🔍 \*\*探索\*\*：科学心理测评，理性认知自我状态。

\## 🔐 安全使用须知

\- 仁归默认仅在本地运行（`127.0.0.1`），不会对外暴露。

\- 如开启局域网访问，请确保处于受信任网络，并设置访问密码。

\- 所有用户输入均经过 XSS 过滤，数据存储使用参数化查询防止注入。

\- 发现安全漏洞请发送邮件至 (https://github.com/rengui-red/rengui-nature-dream/security/advisories/new)，我们会及时修复。
