## 🚀 快速开始

### 零依赖启动（推荐）

1. 下载/克隆本项目。
2. 直接双击打开 `index.html`（语言选择入口）。
3. 选择语言进入对应版本，所有功能立即可用。
4. 数据保存在浏览器 localStorage 中。

🔒 数据与隐私

全部数据仅存储于浏览器本地（localStorage）

不收集任何个人信息

不发送任何网络请求

无第三方追踪脚本

用户可随时清除浏览器数据即完全删除所有记录

详见 隐私政策 和 公司隐私补充说明。

🛠️ 技术栈

层次	技术
前端	HTML5 + CSS3 + Vanilla JS (ES6+)
数据存储	localStorage（键前缀 rengui_）
AI 引擎	规则引擎 + 关键词库（本地）
心理测评	静态量表定义（SAS）
音频	Web Audio API（实时合成）
绘图	Canvas API
后端（可选）	Python Flask + SQLite
