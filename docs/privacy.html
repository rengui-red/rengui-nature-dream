🌿 仁归 · 隐私政策

最后更新：2025年1月

核心承诺：仁归是一个纯本地运行的应用程序。 您的所有数据都存储在您自己的设备上，我们无法访问、收集或看到您的任何信息。

1. 数据收集

我们不收集任何数据。具体而言：

  • 不收集姓名、邮箱、手机号等个人信息
  • 不收集日记内容、测评结果等敏感信息
  • 不收集IP地址、地理位置、设备信息
  • 不使用Cookie或其他追踪技术
  • 不接入任何第三方统计或广告SDK

2. 数据存储

所有数据（日记、测评记录、心愿、画作等）均存储在您浏览器的 localStorage 中：

  • 数据仅存在于您的设备上
  • 清除浏览器数据即可完全删除所有记录
  • 换用其他浏览器或设备不会同步这些数据

3. 数据使用

由于数据完全存储在本地，我们无法使用、分析或分享您的数据。您的数据只属于您自己。

4. 数据删除

您可以随时通过以下方式删除数据：

  • 在浏览器设置中清除该网站的数据
  • 在浏览器中清除 localStorage
  • 直接删除浏览器缓存

5. 第三方服务

仁归不依赖任何第三方服务。AI对话、心理测评、游戏等所有功能均在您本地运行。

6. 儿童隐私

仁归面向所有年龄段的用户。由于我们不收集任何数据，因此也不存在儿童隐私数据的问题。

7. 政策变更

如果我们对隐私政策进行任何变更，我们将在项目中更新此页面。但我们的核心承诺不会改变：不收集、不上传、不追踪。

8. 联系我们

如果您对隐私政策有任何疑问，欢迎在 GitHub 仓库中提交 Issue 或通过开源社区联系我们。

🌿 仁归 · 数据只存本地，心灵只属于你。
