\### 1.3 仁归是什么



\*\*仁归\*\*是一个\*\*开源、免费、本地优先\*\*的心理健康自我探索与情绪陪伴工具。



它不是：

\- ❌ 一个商业公司

\- ❌ 一个医疗机构

\- ❌ 一个心理咨询服务平台

\- ❌ 一个数据收集平台

\- ❌ 一个AI大模型产品



它是：

\- ✅ 一个由社区驱动的开源项目

\- ✅ 一个运行在用户浏览器中的本地应用

\- ✅ 一个基于规则引擎的情感陪伴工具

\- ✅ 一个融入中国传统文化元素的心灵空间



\### 1.4 仁归的定位



仁归 = 公园 + 图书馆 + 安静的房间

\## 二、权利



\### 2.1 用户的权利



| 权利 | 说明 | 法律依据 |

|------|------|---------|

| \*\*数据主权\*\* | 所有数据仅存在于用户浏览器 localStorage，用户完全拥有自己的数据 | 个人信息保护法（数据最小化原则） |

| \*\*知情权\*\* | 所有代码开源，用户可审查每一行逻辑 | 开源透明原则 |

| \*\*删除权\*\* | 随时清除浏览器数据即完全删除所有记录 | 个人信息保护法（删除权） |

| \*\*拒绝权\*\* | 随时可以关闭页面、不再使用，无任何锁定 | 自由选择原则 |

| \*\*修改权\*\* | 用户可自由修改源代码以满足个人需求 | MIT 开源许可 |

| \*\*分发权\*\* | 用户可分享仁归给他人，但需保留开源许可和誓约 | MIT 开源许可 |

| \*\*不被打扰权\*\* | 不接收任何推送、广告、营销信息 | 无商业模型 |

\## 五、法律边界



\### 5.1 我们做什么（合法范围内）



| 功能 | 法律定位 | 合规说明 |

|------|---------|---------|

| AI情感陪伴 | 信息提供工具 | 基于规则引擎，不构成医疗行为 |

| 心情日记 | 用户自我记录 | 数据本地存储，不涉及个人信息处理 |

| SAS心理测评 | 自我评估参考 | 标注"仅供参考"，不构成诊断 |

| 游戏互动 | 娱乐放松 | 无任何赌博或有害内容 |

| 声音疗愈 | 音频播放 | 不涉及医疗声学治疗 |

| 诗意创作 | 文字创作辅助 | 不侵犯他人著作权 |

| 自由绘画 | 绘画工具 | 用户生成内容归用户所有 |



\### 5.2 我们做什么（明确禁止）



| 禁止行为 | 原因 |

|---------|------|

| 不提供医疗诊断 | 需要执业医师资格 |

| 不提供药物治疗建议 | 需要执业药师/医师资格 |

| 不进行危机干预 | 需要专业训练和资质 |

| 不收集用户数据 | 保护隐私，避免合规负担 |

| 不接入任何AI大模型API | 避免数据外泄和合规风险 |

| 不设置付费墙 | 保持公益性质 |

| 不投放广告 | 保持纯粹的治愈空间 |



\### 5.3 风险边界



| 场景 | 仁归的应对 |

|------|-----------|

| 用户表达自杀倾向 | 不进行干预，提供全国心理援助热线（12356） |

| 用户声称自己患有精神疾病 | 不确认也不否认，建议寻求专业诊断 |

| 用户要求医疗建议 | 明确告知"我不能提供医疗建议" |

| 用户是未成年人 | 不收集任何信息，建议在监护人陪同下使用 |



\### 5.4 免责声明

仁归是一个自我探索和情绪陪伴工具，不构成：



医疗诊断



心理治疗



危机干预



专业咨询



AI回应基于规则引擎，不构成任何形式的专业建议。

用户使用仁归即表示理解并接受上述限制。

如有心理健康问题，请咨询专业心理医生。

如有紧急危险，请立即拨打当地急救电话或心理援助热线。
